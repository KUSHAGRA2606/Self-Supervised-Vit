# Segmentation metrics

The initial hard-set attention run used the 20 visually selected cases in the data manifest. Its two metrics are pooled binary target IoU and all-source IoU against photutils. The all-source union has no three-class mIoU. The full 600-ID evaluation is generated by the segmentation notebook after training and validation selection, with any broken pseudo-labels excluded. The five manual exclusions are all in training.
