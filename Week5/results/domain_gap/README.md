# Domain-gap measurements

The pilot uses prepared DESI training examples and finite BTK validation examples. The reported RMS is in native nanomaggies for DESI and native electrons for BTK. Compare the RMS columns within a domain. The r-band aperture S/N and equivalent source radius use the same photutils aperture definition. Seeing uses the DESI catalog PSF metadata and the BTK filter PSF configuration. The CLS figure is a qualitative visualization of the two development samples.
